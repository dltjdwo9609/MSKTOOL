# MSKTOOL

물리치료사·트레이너를 위한 **근골격계 임상 추론 & 동일 연령대 규범 대조 평가** 웹앱입니다.
회원의 성별·만 나이·키·체중을 넣고 측정값을 입력하면, 같은 성별·연령대의 규범과 비교한 지금 위치를 보여 주고 회원에게 건넬 리포트까지 만들어 줍니다. 설치·로그인 없이 브라우저에서 바로 열리는 단일 웹앱입니다.

## 바로 쓰기

**웹 주소: <https://dltjdwo9609.github.io/MSKTOOL/>**

- **휴대폰·태블릿**: 주소를 연 뒤 크롬(안드로이드)은 메뉴의 `앱 설치`, 사파리(아이폰·아이패드)는 `공유 → 홈 화면에 추가`를 누르면 주소창 없는 앱(PWA)으로 열립니다.
- **PC**: 960px 이상 넓은 화면에서는 고객 정보·부위 선택·임상 문진이 나란히 놓이는 2단 레이아웃으로 펼쳐집니다. (모바일은 1단 흐름)
- 인터넷이 끊겨도 마지막으로 받은 화면이 그대로 열립니다(서비스 워커 오프라인 캐시).

## 주요 기능

- **바디차트 10부위** — 목·어깨·팔꿈치·손목·흉추·허리·고관절·무릎·발목·전신. 앞면·뒷면 몸 그림과 빠른 선택 칩이 같은 선택을 공유하고, 고른 부위는 `오른쪽 무릎 ×`처럼 한 줄로 모입니다.
- **임상 문진** — 통증 타입(침해수용성·신경병증성·혼합), 과민성(Irritability: 낮음·중간·높음), PQRST, 신경학적 선별, 부위별 임상 분류·주의신호·재활 가이드. 허리는 0·1·2단계 구조(스크리닝 → 통증 구동 요인 → 서술 라벨)로 정리합니다.
- **가설 우선순위** — 부위별 대표 가설 칩을 눌러 1·2·3순위를 세우고, 중재 계획·해결 상태(미해결·진행중·해결)와 함께 기록. 우선순위를 올리고 내릴 때 중재·해결 상태까지 짝을 맞춰 따라옵니다.
- **증상 수정(SSMP · MWM)** — 동작 하나의 수정 전·후 통증과 조절 방법을 기록해 즉시 반응(0~2점 이하)을 확인하고, 어깨는 SSMP 4단계(흉추·경추 자세 → 견갑골 위치 → 상완골두 → 근수축)로 단계별 반응을 봅니다.
- **동일 성별·연령대 규범 비교** — 45종 검사의 백분위·5단계 위치·동일 연령대 중앙값, 편측 검사의 좌우 비율(LSI, 목표 90%), 재평가 변화량. 규범은 국민체력100(KSPO)·ACSM·Cooper Institute·CDC 등 원문 표에서 확인한 수치만 쓰고, 확인되지 않은 검사는 백분위를 만들지 않고 '참고용'으로 둡니다.
- **연령대 맞춤** — 성인(20~59세)과 시니어(60세 이상)에 따라 추천 검사와 기본 루틴 세트가 자동으로 바뀝니다. 건병증(슬개건·둔근·햄스트링)·어깨 RCRSP 재활 검사 8종과 부위별 임상 검사 9종도 부위를 고를 때 함께 나옵니다.
- **회원용 리포트** — 카톡 공유·저장용 PNG(1080px)와 A4 인쇄(PDF). 영역별 한눈에 요약, 지난 평가 대비 변화, 쉬운 말 설명문 복사. 논문 출처·백분위 같은 학술 표기는 회원용 화면에 넣지 않습니다.
- **회원 기록** — 회원·날짜별로 기기에 저장되고 재평가 때 이전 값이 자동으로 채워지며, JSON 백업/가져오기로 옮길 수 있습니다.
- **선택적 구글 시트 동기화** — 여러 기기에서 같은 기록을 쓰려면 본인 구글 시트에 연결합니다(앱 안내 3단계 + Apps Script 코드 1클릭 복사). 연결하지 않으면 아무 데이터도 외부로 나가지 않습니다.
